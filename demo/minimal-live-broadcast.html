观众端报错如何排查（PK / review / WebRTC）

live_engine_pk / 100411：表示当前房间没有进行中的 PK，服务端返回「battle 不存在或已过期」在无 PK 场景下是预期现象。 若仅刷屏日志：可在业务端忽略该错误，或将 TUILiveKit / RoomEngine 升级到最新；与是否「创建房间多传参」无必然关系。

Cannot read properties of null (reading 'review')：多为观众端业务或 UI 组件假设了某字段（如审核、扩展信息）一定存在。 请对直播元数据使用可选链（liveInfo?.xxx），并与正式主播端创建的字段结构对齐。

WebRTC reading 'type'：多为网络抖动、UserSig 过期、或移动端浏览器策略；请确认 HTTPS、票据未过期、主播仍在推流。

模板 200 / 600 在官方映射里会打开麦位布局。若只做单机位 Canvas、不需要连麦，请不要勾选「开启麦位」，且不必传 seatLayoutTemplateId，可减少观众端麦位/PK 相关模块的空数据访问。
