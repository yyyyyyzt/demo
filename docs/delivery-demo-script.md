# 交付 Demo · 演示脚本（生产标准）

面向产品 / 运营 / 研发演示。前置：已按 `.env.example` 配置 `TRTC_*`、`IVH_*`、`IM_REST_ADMIN_USER_ID`，并在控制台开启 TRTC「输入媒体流进房」、TUILiveKit、IM、数智人；准备一台装好 OBS 的机器。执行 `npm run dev`。

## 1. 创建直播间（约 30 秒）

1. 打开 `http://127.0.0.1:5173/admin`。
2. 输入标题（如「惠民政策宣讲专场」）→ 创建。
3. 复制本房间的 **观众链接**、**管理员 A / B 链接**。

## 2. 开播并拿到 OBS 地址（约 1 分钟）

1. 打开管理员 A 链接 `/studio/:roomId?mod=a`，点 **开始直播（生产 · OBS 拉流转推）**。
2. 右侧「OBS 拉流转推地址」面板出现：① 拉流地址、② 推流地址。

## 3. OBS 拉流 → 处理 → 推流（约 2 分钟）

1. OBS 添加「媒体源」，填 ① 拉流地址（FLV/RTMP）。
2. 加「色度键」滤镜抠像，叠加虚拟背景图层与装修贴图（Logo / 下沿标题）。
3. 设置 → 推流 → 自定义：服务器 `rtmp://rtmp.rtc.qq.com/push/`，串流密钥填 ② 去掉前缀的部分 → 开始推流。

详见 [OBS 拉流转推管线](obs-pull-push-pipeline.md)。

## 4. 观众看播 + 评论（约 1 分钟）

1. 手机/新窗口打开 **观众链接** `/live/:liveId`，看到 OBS 合成画面。
2. 在观众端发一条评论 → 评论真走 IM，出现在播控台与公开评论流。

## 5. 评论播控：模型回复 → 编辑 → 播报（约 1 分钟）

1. 播控台左侧选中评论 → **模型回复** 生成话术（认领锁防止两管理员撞车）。
2. 中间编辑框二次加工 → **播报给数字人** → 数智人开口，观众端可见可听。
3. 对不良评论点 **撤回**（IM 撤回）、对发送者点 **禁言**（IM 禁言）。

## 6. 多管理员协作

把管理员 B 链接发给第二位运营，二人交替认领评论回复。

## 7. 结束

播控台点 **结束直播**：关闭数智人会话、释放并发、（可选）销毁 TUILiveKit 房间。
