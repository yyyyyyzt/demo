# 交付 Demo · 5 分钟演示脚本

面向产品经理 / 客户演示。前置：已配置 `.env` 中 `TRTC_*` 与 `IVH_*`，执行 `npm run dev`。

## 1. 创建房间（约 30 秒）

1. 浏览器打开 `http://127.0.0.1:5173/admin`（端口以 Vite 输出为准）。
2. 输入房间标题，点击 **创建**。
3. 在列表中点击 **开始数字人播报直播**，进入播控台。

## 2. 开始直播（约 1 分钟）

1. 在播控台点击 **开始数字人播报直播**。
2. 等待右侧预览出现数字人画面（首次约 30–90 秒，视云端就绪速度）。
3. 底部状态条应显示 `SessionId` 与 `live`。

## 3. 评论 → 生成 → 改稿 → 播报（约 2 分钟）

1. 点击 **注入测试评论**（可多次注入 2 条）。
2. 选中一条评论，点击 **生成回复**，右侧文本框出现回复文案。
3. 在文本框中**手动修改**一两个字（证明可改稿）。
4. 点击 **播报**，观察数字人朗读修改后的文案；同 Session 画面应**连续不闪断**。
5. 对第二条评论重复：生成 → 播报。

## 4. 监控窗口（约 30 秒）

1. 回到管理台，对同一房间点击 **监控窗口**（新标签页）。
2. 确认监控页能看到**同一 liveId** 下数字人画面与 Session 状态。
3. 回到播控页再播报一句，监控页画面应同步变化（可能有数秒延迟）。

## 5. 结束直播（约 20 秒）

1. 播控台点击 **结束直播**。
2. 预览断开；`GET /api/rooms/:id/studio/session` 中 `active` 为 false。

## 故障排查

| 现象 | 检查 |
|------|------|
| `ivhConfigured: false` | `.env` 三项 `IVH_*` 是否填写并重启 API |
| 有声音无画面 | 是否使用播控/监控页原生 TRTC 预览（非 TUILiveKit LiveView） |
| 播报 409 | 是否先 **开始直播** |
| 画面闪断 | 确认未设置 `IVH_AUTO_CLOSE_SESSION=1` |

## 命令行冒烟（可选）

```bash
chmod +x examples/studio-smoke.sh
./examples/studio-smoke.sh <room_internal_id>
```
